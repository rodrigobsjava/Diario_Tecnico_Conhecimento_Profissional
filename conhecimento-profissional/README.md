# Diário Técnico — Conhecimento Profissional

Este repositório é um sistema pessoal de aprendizagem contínua.

## Regra principal

Não transformar o diário em um depósito de teoria copiada.

Registrar principalmente:
- problemas encontrados;
- lacunas de conhecimento;
- descobertas;
- erros e causas;
- soluções compreendidas;
- decisões técnicas;
- experimentos de laboratório;
- aprendizados que possam ser reaplicados.

> **Importante:** experiências do trabalho podem alimentar o aprendizado, mas nunca devem levar código, dados, credenciais ou informações internas da organização para este repositório.

## Perguntas-base

Para conceitos estudados:

1. O que é?
2. Por que existe?
3. Quando usar?
4. Como funciona?
5. Qual problema resolve?
6. Quais alternativas existem?
7. Qual erro comum?
8. Como testar?

## Fluxo

Problema → Lacuna → Estudo → Laboratório → Documentação → Aplicação → Competência
